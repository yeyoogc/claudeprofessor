Cómo instalar las skills de Claude

Las skills oficiales de Anthropic son gratis y están publicadas. Lo que casi nadie explica es dónde se activan y por qué a veces instalas una cosa y te falta la mitad.

Lo primero, para ahorrarte tiempo: si usas Claude desde la web o la app de escritorio, no tienes que instalar nada. Ya están ahí, solo hay que encenderlas. Instalar solo hace falta en Claude Code.

Ruta 1 · La app de Claude

Sin terminal, sin comandos

Funciona en los planes Free, Pro, Max, Team y Enterprise. Son dos ajustes distintos y en sitios distintos, y ese es justo el paso donde se atasca todo el mundo: activar las skills sin lo primero no sirve de nada.

  1. Activa la ejecución de código. En Ajustes → Capacidades, enciende «Ejecución de código y creación de archivos». Las skills la necesitan para funcionar: sin esto no aparecen o no hacen nada.
  2. Enciende las skills. Ahora ve a Personalizar → Skills y activa las que quieras, una a una.
  3. Úsalas. No hay que llamarlas. Claude lee la descripción de cada skill y la carga sola cuando la conversación encaja. Si quieres forzarla, nómbrala: «usa la skill doc-coauthoring».
Si estás en un plan de empresa y no ves las opciones, no es cosa tuya: el propietario de la organización tiene que habilitarlas antes en Ajustes de organización → Skills.

Ruta 2 · Claude Code

Dos comandos, y hay que poner los dos

Aquí sí se instalan. Primero registras el repositorio de Anthropic como mercado de plugins:

/plugin marketplace add anthropics/skills

Y después instalas los paquetes. Son dos y necesitas los dos, porque las skills de escribir están repartidas entre ellos: si instalas solo uno te faltan la mitad y acabas pensando que la skill no existe.

/plugin install example-skills@anthropic-agent-skills
/plugin install document-skills@anthropic-agent-skills

Luego se usan mencionándolas sin más: «Usa la skill pdf para sacar los campos de este formulario».

Hacer la tuya

Una skill es una carpeta con un archivo dentro

No hay más misterio: una carpeta con un SKILL.md que empieza por un bloque con name y description. Esa descripción es lo único que Claude lee para decidir si la skill aplica, así que es la parte que hay que escribir con cuidado: si dice cuándo usarla en palabras concretas, se activa cuando toca.

---
name: escribe-como-yo
description: Aprende mi voz a partir de textos míos antes de
  escribir nada. Úsala cuando te pida escribir un texto que
  tenga que sonar a mí.
---

# Instrucciones que Claude va a seguir…

En Claude Code se copia a la carpeta de skills de tu usuario:

cp -r mi-skill ~/.claude/skills/

Y en la app de Claude se sube comprimida en ZIP desde Personalizar → Skills, botón + → Crear skill → Subir una skill.

El atajo: instala skill-creator y pídele que escriba la skill por ti. Le das tres textos tuyos y te devuelve tus reglas escritas, que es exactamente lo que no vas a acordarte de repetir en cada chat.
