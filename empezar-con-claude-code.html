Empezar con Claude Code

Un chat te contesta; Claude Code trabaja donde trabajas tú — abre tus carpetas, corre los comandos y escribe los cambios. Se instala en una línea y en cinco minutos le pides la primera cosa. Esto es lo justo para arrancar.

Qué es, en una frase

Claude Code es Claude instalado en tu ordenador, en la terminal (y también en el editor, en una app de escritorio o en el navegador). No es una pestaña a la que le pegas texto: ve tus archivos, ejecuta comandos, edita el código y trabaja con git. Va con tu suscripción de Claude de pago; no se paga aparte.

01 · Instalarlo, una línea

En la terminal de tu Mac, Linux o WSL:

curl -fsSL https://claude.ai/install.sh | bash

En Windows con PowerShell es irm https://claude.ai/install.ps1 | iex. También está en Homebrew (brew install --cask claude-code) y como extensión de VS Code y JetBrains. La primera vez te pide iniciar sesión con tu cuenta de Claude.

02 · Abrirlo en tu proyecto

Vas a la carpeta de tu proyecto y lo arrancas. Ese cd importa: Claude Code trabaja sobre la carpeta desde la que lo abres.

cd mi-proyecto
claude

03 · Las tres primeras cosas que le pides

Aquí se ve la diferencia con un chat. No le pegas nada: se lo dices y lo hace.

  • Que lo entienda: «lee esta carpeta y dime qué hace este proyecto». Lo lee él solo, no se lo pegas.
  • Que lo arregle: «hay un fallo cuando hago X, encuéntralo y arréglalo». Busca, edita el archivo y te enseña el antes y el después.
  • Que lo guarde: «guarda esto con un buen mensaje». Prepara el cambio, escribe el mensaje y hace el commit.

Cuándo sigue ganando el chat

No es uno contra otro. Para una duda suelta, una idea rápida o cuando no tienes el proyecto delante, abrir un chat es más rápido. Claude Code es para cuando hay que TOCAR cosas: archivos, comandos, tu repositorio.

El siguiente paso

Cuando le cojas el aire, dos cosas lo cambian de nivel: enseñarle una skill con tu forma de trabajar, y añadirle plugins desde su tienda. Pero eso es para después; hoy, instálalo y pídele la primera.
